# Analysisbanking

**Analysisbanking** — это инструмент для анализа банковских транзакций, предоставляющий отчёты по категориям расходов, курсам валют и ценам на акции. Проект разработан с использованием Python и предназначен для персонального финансового анализа.

## 🚀 Установка

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/VladislavL001/Analysisbanking.git
   cd Analysisbanking

2. **Создайте виртуальное окружение и активируйте его:**

    ```bash
    python -m venv venv
    source venv/bin/activate  # Для Windows: venv\Scripts\activate

3. **Установите зависимости:**

    ```bash
   pip install -r requirements.txt


## ⚙️ Запуск

1. **Настройте переменные окружения:**
    Создайте файл .env на основе .env.example и укажите необходимые параметры.

2. **Запустите основной скрипт:**

    ```bash
   python main.py
